# vLend Website

Landing page for the [vLend Protocol](https://github.com/visualisaxyz/vlend) — a collateralized borrowing protocol for the MegaETH ecosystem.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS (minimal, mostly custom CSS)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3010](http://localhost:3010).

## Build

```bash
npm run build
npm start
```

## Configuration

- **App URL**: Set `NEXT_PUBLIC_APP_URL` in `.env` to point "Launch App" / "Open App" buttons to your dApp. See `.env.example`.

## Deploy

Optimized for [Vercel](https://vercel.com). Connect the repo and deploy.
